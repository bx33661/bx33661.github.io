# CNVD-2026-20654: LG NAS Remote Command Injection Vulnerability

## Vulnerability Details

- **Vulnerability ID**: CNVD-2026-20654
- **Vulnerability type**: OS command injection (CWE-78)
- **Severity**: High
- **Attack vector**: Network (remote)
- **Privileges required**: Low (a valid account is required)
- **User interaction**: None
- **Impact**: Full system control with root privileges

### Vulnerable Code Locations

**Line 28** (`share_set_user_info.php`):

```php
$userpasswd = trim(shell_exec("sudo nas-common md5$userpasswd"));
```

![Vulnerable code, line 28](/blog/cnvd-lg-2026-20654/01-vulnerable-code-line28.png)

**Line 78** (`share_set_user_info.php`):

```php
$check = trim(exec("sudo nas-share check_user$userID"));
```

![Vulnerable code, line 78](/blog/cnvd-lg-2026-20654/02-vulnerable-code-line78.png)

### Cause

The cause is straightforward:

1. User input is concatenated directly into a shell command.
2. Special characters are not filtered or escaped.
3. The command is run with sudo, gaining root privileges.
4. shell_exec() and exec() directly execute system commands.

## Summary

CNVD-2026-20654 is a typical command injection vulnerability: unfiltered user input is concatenated directly into a shell command, and combined with sudo privileges, an attacker can gain complete control of the device. The vulnerability affects multiple firmware versions. Affected users are advised to upgrade the firmware promptly and strengthen access controls.
