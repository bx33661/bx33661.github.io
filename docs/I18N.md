# 同一站点的中英文支持

英文是原站的语言版本，不是独立的站点或设计系统。中文保持既有 URL，英文使用 `/en/` 前缀。布局、导航、列表、阅读组件、样式与交互都由同一份实现维护；路由文件只负责取对应语言的数据。

## 共用页面与组件

| 页面 | 中英文共用实现 |
| --- | --- |
| 首页 | `AcademicHome.astro`，仅入口链接按语言变化 |
| 文章列表及分页 | `BlogIndex.astro` + `EntryRow.astro` + `Pagination.astro` |
| 笔记索引 | `NotesIndex.astro` + `EntryRow.astro` |
| 全部笔记及分页 | `NotesList.astro` + `EntryRow.astro` + `Pagination.astro` |
| 归档 | `ArchiveIndex.astro`，同样的年份、月份与日期索引 |
| 搜索 | `SearchPage.astro`，同样的搜索框与搜索交互 |
| 文章详情 | `PostDetails.astro`，同样的目录、代码复制、图片查看器和相关阅读 |
| 笔记详情 | `NoteDetails.astro`，同样的摘要、正文与前后篇 |

所有页面继续使用原有 `Layout`、`Header`、`Footer`。没有独立英文壳、侧栏、空书架插画或 `english-*` 样式。界面文案集中在 `src/i18n/ui.ts`；已有导航、页脚和搜索运行时仍在原组件中按语言取文案。样式不按语言分叉。

友链、相册继续使用原有共享地址，不生成没有译文的镜像；两种语言的导航都保留这些入口。英文的标签入口使用英文搜索，避免链接到不存在的英文标签页。

## 路由与内容

- `/en/`：共用原有英文首页介绍。
- `/en/about/`：跳转到 `/en/`，与原站首页/关于页关系一致。
- `/en/blog/`、`/en/blog/2/` 等：英文文章，使用原站分页逻辑。
- `/en/notes/`、`/en/notes/list/` 及后续分页：英文笔记。
- `/en/archives/`：仅收录真实英文文章。
- `/en/search/`、`/en/search.json`：英文搜索与开发索引。
- `/en/rss.xml`：独立的英文文章 feed。
- `/en/blog/<slug>/`、`/en/notes/<slug>/`：仅为真实、公开的英文内容生成。

文章和笔记仍存在同一组内容集合中，元数据以 `src/content.config.ts` 为准。`lang` 默认 `zh-CN`，英文内容明确设置 `lang: en`。本次不翻译、复制或重新分类既有内容。

```yaml
---
title: "An English article"
description: "An English description of the research and its reproducible findings."
date: 2026-10-18
lang: en
slug: english-article
tags: [Security]
authors: [bx]
draft: true
# 只有确实互为译文时，双方才使用相同的键。
translationKey: research-example
---
```

没有英文文章时，原站列表显示简短的空内容提示并链接中文原文，不填充样例或把中文标题伪装成英文内容。英文文章沿用原站 Markdown/MDX、数学公式和嵌入组件；嵌入组件自己的文案由作者确认。

## 切换、搜索与 SEO

语言切换优先使用明确且唯一的 `translationKey` 配对。同集合内不存在译文时，切换入口明确标注没有对应译文，链接另一语言的集合页或首页，不猜测文章 URL，也不按浏览器语言强制跳转。

两种语言各自保留正确的 `lang`、canonical、RSS、结构化数据语言与搜索索引。真实译文使用 `hreflang` 关联；不把英文 canonical 指向另一语言。空英文集合为 noindex 且不进入 sitemap。搜索为 noindex。

Pagefind 按页面语言检索。没有英文索引时显示英文空结果，禁止悄悄回退到中文结果。ClientRouter 离开页面时销毁搜索实例，往返切换不残留上一语言索引。文章与笔记的前后篇同样限定当前语言。

## 验证

```bash
node --test scripts/i18n.test.mjs scripts/i18n-shared-ui.test.mjs
npm run verify:full
node scripts/i18n-browser.mjs
# 仅在隔离的测试副本中加入真实结构的合成内容：
I18N_FIXTURE=1 node scripts/i18n-browser.mjs
```

语言浏览器检查覆盖桌面/手机、明/暗主题，对比两种语言对应页面的实际计算样式；检查同一导航、语言切换、空结果与真实搜索、RSS/sitemap 隔离和横向溢出。带内容副本还检查共用文章阅读布局、目录、复制按钮、笔记、归档入口和译文往返。截图保存在 `.visual-artifacts/i18n/`。
